## 1. 主题定义

本主题归并“如何把日内价格、成交量、订单流或跨周期信号转化为可交易的标准化信号”这一类文献知识。它覆盖三种相互补充的信号生成思路：第一，先将原始状态变量标准化，再通过阈值或双阈值机制触发交易；第二，将价格位置和成交量异常组合为事件型信号；第三，将多个弱信号或方向信号进行分散化聚合，减少单一信号的偶然性。对期货日内因子挖掘来说，该主题不是直接给出最终因子，而是给出一套从字段到信号的转换框架：定义基准、度量偏离、过滤噪声、控制交易频率，并把所有统计量限制在当时可得的信息集合内。

`doc_06` 是本主题中与目标场景最接近的文献。它直接使用中证1000股指期货 IM 的 Level-2 高频数据，围绕订单簿买卖对比、流动性失衡和小单主导度构建资金流因子，并用 Z-score 和 Hysteresis 双阈值把因子转化为开平仓信号。`doc_07` 来自股票高频量价事件策略，核心是价格高低位与成交量放大共同出现时才触发事件。`doc_10` 与 `doc_15` 的频率较低，但分别提供“弱信号分散化”和“多方向信号归一化融合”的方法论。`doc_01` 虽然与日内动量相关，但当前存在 page-only locator 硬失败，本版主题不把它作为强证据。

## 2. 核心机制与共识

跨文献看，信号标准化的共同目标不是让原始字段本身“更平滑”，而是把不同时间、不同状态下不可比的观测值转成相对于自身历史或市场状态的偏离度。`doc_06` 中的 Z-score 把当前因子值转为“离滚动均值多少个标准差”，从而让订单簿类因子在不同合约阶段、不同波动环境下更可比。这个结论说明：日内信号不能只看绝对值，必须先定义“正常状态”或“历史基准”。

第二个共识是，交易触发应避免把微小扰动当成方向信息。`doc_06` 的 Hysteresis 双阈值把开仓阈值和平仓阈值分开，降低信号在阈值附近反复翻转的概率。这个机制与 `doc_07` 的事件簇思想一致：单一价格高位或单一放量都不足以构成稳健信号，价格位置与成交量异常共同出现才更值得记录。换句话说，入场、持有和平仓最好使用分层条件，避免用同一个阈值承担全部功能。

第三个共识是，单个信号的显著性不能替代组合后的稳定性。`doc_10` 在噪声 Alpha 环境下发现，严格只保留统计显著信号并不一定优于聚合大量弱信号和零信号；信号分散化能够在噪声较重时提高组合稳定性。`doc_15` 在跨资产配置中使用价值、动量、Carry 与波动率管理四类方向信号，经 tanh 归一化和波动率翻译后形成权重偏移。虽然它们的原始频率与本项目不同，但“先标准化方向，再限制幅度，再按风险状态缩放”的流程可迁移到日内特征组合。

## 3. 关键公式与方法谱

### 3.1 Z-score 偏离度

来源：`doc_06`

```text
Z_t = (X_t - mu_t) / sigma_t
```

其中 `X_t` 为当前因子值，`mu_t` 与 `sigma_t` 为滚动窗口内的历史均值和标准差。迁移到本项目时，`mu_t` 与 `sigma_t` 必须只使用 `t` 之前可得数据估计，不得包含未来快照；当 `sigma_t = 0` 或窗口历史不足时，应返回缺失、沿用安全默认值，或进入异常标记，而不能用任意小数硬除。窗口可按研究约束候选值 `3/5/15/60` 秒测试，也可按快照数量实现，但报告中必须写清二者映射。

### 3.2 Hysteresis 双阈值

来源：`doc_06`

方法定义：用较高阈值触发开仓，用较低阈值触发平仓，形成缓冲带。该方法的核心不是固定参数本身，而是“开仓需要更强证据，平仓允许更温和信号”的状态机思想。首轮特征设计中可将阈值写成：

```text
open_long if Z_t >= theta_open
close_long if Z_t <= theta_close
theta_open > theta_close
```

对空头可使用对称规则。若引入动态缓冲带，只能作为待验证扩展，不能写成原文已证明有效。

### 3.3 价格位置与成交量事件

来源：`doc_07`

原文事件定义类似：

```text
P_t > P_{90%} and V_t > V_{90%}
```

其中分位数来自历史价格序列和成交量序列。迁移到期货日内时，更合适的表达是“价格在短窗口内处于高/低分位，同时成交量或成交量增速处于高分位”。它适合生成事件计数、事件持续时间、事件后回撤和事件后成交量衰减等特征，但不能直接照搬股票日度调仓和 VWAP 执行假设。

### 3.4 弱信号分散化与归一化融合

来源：`doc_10`, `doc_15`

`doc_10` 的信息比率公式为：

```text
IR = alpha_hat / omega_hat
```

并使用 FDP 思路讨论虚假发现。`doc_15` 的信号到权重偏移公式为：

```text
Delta w_{i,t} = tanh((1/4) * sum_f S_{f,i,t}) * TargetVol / sigma^{clipped}_{i,t}
```

这两篇不直接给出期货日内因子，但共同支持一个方法论：不要只保留看起来最显著的少数信号；可以先构造多尺度、多字段的弱特征池，再用相关性、稳定性和增量检验控制入池。首轮不应把该结论理解为“弱信号一定有效”，而应把它转化为检验设计：比较单强信号、简单等权弱信号组、标准化后融合信号三者的样本外表现。

## 4. 数据处理与检验共识

本主题的共同数据处理步骤包括：先确认字段可获得时点，再计算差分或滚动统计量，再标准化，再生成状态或事件，最后进入检验。任何需要历史均值、历史标准差、分位数或成交量均值的特征，都要写明统计量估计区间。若统计量来自当日已发生数据，应避免在开盘早段历史不足时生成强信号；若来自历史交易日，应说明是否违反当前项目“不跨交易日使用历史状态”的约束。

检验上，`doc_06` 强调全样本回测、参数敏感性、交易成本和换月空窗期效应；`doc_07` 强调收益、卡玛比率和极端市场阶段表现；`doc_10` 提醒要区分样本内筛选与样本外评估。对本项目而言，至少应记录 IC/RankIC、方向准确率、样本内外切分、参数选择区间、交易成本、延迟和平仓规则。若只是同期事件解释，不能写成未来预测因子。

## 5. 分歧、失败与边界

第一个分歧是“标准化是否足以产生稳定收益”。`doc_06` 给出了 IM Level-2 资金流因子的费后表现和参数敏感性，但该结论仍需要在本项目的数据口径、窗口和交易成本假设下重新验证。因此本项目不能把 Z-score 当作天然有效的因子，只能把它作为候选变换和信号生成器。

第二个分歧是“筛选少数强信号还是聚合大量弱信号”。`doc_10` 支持在噪声环境下分散化聚合，但它的原始场景是月度基本面信号，不是秒级期货；`doc_15` 的信号融合也来自宏观资产配置。迁移到日内场景时，必须重新验证高频噪声、交易频率、延迟和成本是否吞噬组合收益。

第三个边界是交易可实现性。`doc_07` 的股票策略使用日度调仓和 VWAP 执行；`doc_06` 使用单边手续费假设。期货日内策略若要落地，必须将费率、最小变动价位、盘口深度、成交约束和最终日内平仓纳入检验。只报告毛收益或不含延迟的信号表现不足以支持入池。

## 6. 项目适配与后续扩展

对路线一，建议把本主题转化为三类字段驱动候选：一是标准化偏离类，例如价格、成交量、买卖盘量差、持仓量变化相对于短窗口均值的 Z-score；二是事件触发类，例如价格处于短窗口高分位且成交量突增，或盘口失衡与成交量放大同时出现；三是状态机类，例如双阈值开平仓、事件持续时间和信号冷却时间。

对路线二，建议优先复现或迁移 `doc_06` 的 Z-score 与 Hysteresis 框架，用 `doc_07` 的事件触发机制做组合条件，用 `doc_10` 和 `doc_15` 检验多弱信号融合是否提高样本外稳定性。每条候选都必须输出所需字段、公式、适用窗口、异常处理、预测标签、预期方向和放弃条件。

首轮放弃条件建议设置得足够硬：如果某类标准化信号在样本外 RankIC 接近 0 且方向准确率不高于随机基准，或者加入交易成本后收益消失，或者对 `3/5/15/60` 秒窗口的方向高度不稳定，则不进入特征登记册；如果只有样本内显著、换期或换品种后消失，应进入“弱证据/想法 backlog”，不能进入候选因子库。
